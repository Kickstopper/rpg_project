# PROJECT ANATTA

**Wizardry / Persona 스타일의 1인칭 던전 크롤러 RPG**

Unity와 C#을 기반으로 개발 중인 **1인 개발 RPG 프로젝트**입니다.

고전적인 **Wizardry-like 던전 크롤러**를 기반으로,
**그리드 기반의 던전 탐색**, **턴제 배틀 시스템**, **레이케스팅 기반의 1인칭 화면**을 결합하고, 이를 **SF 세계관**으로 재해석하는 것을 목표로 합니다.

# 게임 플레이

## 그리드 기반의 던전 탐색

플레이어는 격자로 구성된 던전을 **1인칭 시점**으로 탐색합니다.

이동은 Grid 단위로 이루어지며, 회전 역시 90도 단위로 제한됩니다.

이를 통해 자유 이동 방식의 3D 게임과는 다른, 고전적인 던전 크롤러 특유의 탐색 경험을 구현합니다.

주요 요소:

* Grid 좌표 기반 이동
* 90도 단위 회전
* 이동 가능 영역 및 충돌 판정
* 위치 기반 이벤트
* 던전 오브젝트와의 상호작용
* 함정 및 이벤트 처리

---

## Raycasting 기반 1인칭 화면

던전은 **Raycasting**을 이용하여 1인칭 화면으로 표현합니다.

게임 플레이의 핵심인 Grid 구조와 화면 표현을 분리하여, 던전의 논리적인 구조는 Grid 단위로 관리하면서 플레이어에게는 1인칭 시점의 공간으로 보여주는 것을 목표로 합니다.
```text
### 렌더링 구조

Grid Map
   │
   ▼
플레이어 위치 / 방향
   │
   ▼
Raycasting
   │
   ├── 벽 감지
   ├── 거리 계산
   └── 시야 판정
   │
   ▼
1인칭 화면 렌더링
```

# 턴제 전투 시스템

전투는 **턴제 전투 시스템** 으로 진행됩니다.

플레이어는 캐릭터와 몬스터의 행동 순서를 고려하여 공격, 스킬, 아이템 등의 행동을 선택합니다.

### 주요 시스템

* 턴 순서 관리
* 캐릭터 행동 선택
* 스킬 실행
* 데미지 계산
* 속성 및 상성
* 상태 이상
* 몬스터 AI
* 전투 결과 처리

전투 시스템은 각각의 기능을 독립적인 시스템으로 구성하여 새로운 스킬이나 상태 이상 등의 콘텐츠를 추가할 수 있도록 설계하고 있습니다.

---

# 몬스터 시스템

게임에는 다양한 신화와 전승을 기반으로 한 몬스터가 등장합니다.

플레이어는 전투뿐만 아니라 몬스터와의 상호작용을 통해 파티를 구성하고, 몬스터의 능력을 전략적으로 활용할 수 있습니다.

### 주요 기능

* 몬스터 데이터 관리
* 몬스터 능력치
* 스킬 시스템
* 몬스터 영입
* 몬스터 합체
* 몬스터 AI
* 속성 및 상태 이상

---

# 데이터 중심 설계

게임 콘텐츠와 시스템 로직을 분리하여 새로운 콘텐츠를 추가하기 쉽도록 구성하고 있습니다.
